# FastLoader

Мод для Minecraft 1.7.10 (Forge 10.13.4.1614 + GTNH mixins), цель которого — сильно ускорить загрузку игры с модами.
Первый шаг — **профайлер запуска**: он записывает подробный лог загрузки от старта JVM до главного меню,
чтобы было видно, на что именно уходит время.

## Что пишется

После запуска игры в папке `logs/fastloader/` появляются:

| Файл | Что внутри |
|------|-----------|
| `latest-live.log` | Пишется в реальном времени, построчно с flush. Если игра зависла или упала при загрузке — последняя строка `> ...` без парной `< ...` показывает, где именно. |
| `latest-report.txt` | Итоговый отчёт после выхода в главное меню (на выделенном сервере — после `Server started`). Если игра упала или была закрыта раньше — отчёт всё равно пишется по собранным данным. |
| `latest-sections.csv` | Все секции дерева загрузки в CSV (для Excel/скриптов, сравнения запусков). |
| `history/` | Копии отчёта и CSV каждого запуска с датой — чтобы сравнивать до/после оптимизаций. |

После загрузки мира в `latest-live.log` дописывается и время загрузки мира.

## Разделы отчёта

1. **Timeline** — вехи: старт JVM → загрузка coremod'а FastLoader → `Minecraft.startGame` → окно/OpenGL готовы →
   construction/preInit → ванильная инициализация (звуки, шрифты, текстуры) → init/postInit/loadComplete →
   главное меню. Время между вехами показывает крупные фазы.
2. **Load tree** — дерево: полосы загрузки FML со сплэш-экрана (считываются фоновым потоком каждые 5 мс, без
   патчинга `ProgressManager` — его в сборках грузят слишком рано для Mixin), состояния FML `LoadController` с
   обработчиком каждого мода, `refreshResources`, каждый слушатель ресурсов и сборка каждого атласа текстур. Для каждой секции: общее время, «self» (не покрытое детьми),
   % от всего запуска, время GC и сколько классов загружено.
3. **Slowest individual steps** — топ-40 самых долгих шагов.
4. **Mods** — время каждого мода в Construction / PreInit / Init / PostInit / LoadComplete.
5. **Resource reload listeners** — время каждого слушателя перезагрузки ресурсов и сколько раз ресурсы перезагружались.
6. **ASM class transformers** — сколько времени ушло на каждый трансформер coremod'ов (по сэмплам стека; точные
   таймеры — опционально, см. ниже).
7. **JVM** — GC по сборщикам, время JIT, число классов, память.
8. **Hints** — автоматические подсказки (много GC, дорогие трансформеры, повторные перезагрузки ресурсов, долгая
   склейка текстур).
9. **Profiler hooks** — какие хуки сработали. Все mixin'ы профайлера необязательные (`required: false`): если в
   сборке какой-то не применился, игра не падает, а здесь будет `NOT FIRED`.
10. **Sampled profile** — стек потока загрузки снимается каждые 10 мс, ничего в игре не патчится: сколько времени
    ушло на загрузку классов, код каких пакетов/модов был на стеке и самые «горячие» методы.

## Настройки (JVM-аргументы)

| Аргумент | По умолчанию | Описание |
|----------|--------------|----------|
| `-Dfastloader.profiler=false` | включён | Полностью выключить профайлер |
| `-Dfastloader.profiler.transformers=true` | выключен | Точные таймеры на трансформерах классов. Подменяет элементы списка трансформеров, поэтому может конфликтовать с coremod'ами, которые ищут себя в этом списке |
| `-Dfastloader.profiler.stacks=false` | включён | Выключить сэмплирование стека |
| `-Dfastloader.profiler.stackSampleMs=10` | `10` | Интервал сэмплирования стека |
| `-Dfastloader.profiler.minMs=20` | `20` | Секции короче этого сворачиваются в отчёте и не пишутся в live-лог |
| `-Dfastloader.profiler.sampleMs=5` | `5` | Как часто считываются полосы загрузки FML |

## Ограничения

- Время до загрузки coremod'а FastLoader (лаунчер, LaunchWrapper, более ранние coremod'ы) видно только одной цифрой.
- Сэмплирование и таймеры трансформеров начинаются с `Minecraft.startGame` / первого состояния FML; то, что было
  раньше, не учитывается.
